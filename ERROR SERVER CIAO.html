Guida – CIAO non si apre

Questa guida è dedicata ai casi in cui CIAO non si apre e mostra un errore di connessione con il server.

Si raccomanda di non intervenire sulla stampante fiscale, poiché il problema non dipende da essa.

Verifica server – Personality Server

verifica i server global-iss / global-util sono pingabili da Personality Server?

Ticket – Assegnazione

Aprire un ticket e assegnarlo a SSS North America - POS Triage - 3rd Level Support

  • Categoria: RETAIL > IN STORE TECH > POS SW > CIAO Optical > CIAO - Server Connection
  • Categoria: RETAIL > IN STORE TECH > POS SW > CIAO Sun > CIAO - Server Connection

Individuazione VM – Dell EMC

Chiedere allo store di individuare la macchina virtuale denominata Dell EMC.

Se hanno difficoltà, inviare via Teams la foto del server per facilitarne l’identificazione.

Power cycle server Dell EMC

  1. Chiedere allo store di spegnere il server Dell EMC dall’apposito pulsante.
  2. Staccare il cavo di alimentazione per circa 10 secondi, quindi ricollegarlo.
  3. Per verificarne l’esito, attendere almeno 15–20 minuti.
